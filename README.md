# DevSecOps Security Guardrails for a Python API CI/CD Pipeline

## Project summary

This project demonstrates how lightweight DevSecOps security guardrails can be added to a small Python API.

The aim is to show how security checks can be introduced earlier in the software development lifecycle using a simple CI/CD pipeline.

This is a learning project using simulated examples only. It does not contain real company code, real secrets, internal screenshots or production data.

## Business problem

Engineering teams need to release software quickly, but security issues can create risk when they are discovered too late.

Common risks include:

- Insecure coding patterns
- Vulnerable dependencies
- Hardcoded secrets
- Container image vulnerabilities
- Unclear remediation ownership
- Security findings that are difficult for developers to understand

## DevSecOps objective

The objective of this project is to demonstrate how automated security checks can help developers identify and fix issues earlier in the SDLC.

The project will include:

- A small Python API
- A GitHub Actions security pipeline
- SAST scanning
- Secrets scanning
- Dependency scanning
- Container scanning
- Risk-based remediation documentation
- Developer-friendly security guidance
